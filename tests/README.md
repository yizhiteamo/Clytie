# 离线测试数据

所有示例与测试夹具均手写，不使用真实聊天、事件、记忆或由真实数据变换的内容。

- 身份使用 `owner`、`companion_a`、`member` 等逻辑名。
- 示例账号只使用预留的虚构范围 `1000000000` 至 `1000000099`。
- 消息、事件与资产标识用可辨识的重复十六进制字符或由虚构内容计算的哈希。
- 时间使用固定 UTC 时间和 `MockClock`；随机值使用带固定种子的独立生成器。
- 模型与平台使用 `sdk.testing` 和参考假插件，无真实调用与发送。

运行 `uv run --no-sync pytest`。pytest 只收集 `tests/` 与 `plugins/*/tests/`。公共内容检查的负面测试在内存中组合虚构敏感样式，避免把疑似凭据保存为测试文件。

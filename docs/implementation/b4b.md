# B4b 成员准入与工具范围

- `owner_present` 对登记群直接准入；其他已观察群通过逻辑账号查询，仅 `True` 准入。缓存十分钟，成员变动通知在入站认领前清除；查询期间发生变动时拒绝旧结果。私聊规则保持 B4a。
- 入站和出站共用判定；查询有本体五秒上限，未知结果不缓存，期限及取消由注入时钟驱动。交付期限在准入尚未完成时到达，不调用平台，返回 `failed/not_admitted`；迟到的准入成功不能发送。
- qq-onebot 只用标准 `get_group_member_info`，校验返回的群和成员；失败、无效或未知返回视为未知，不猜测“成员不在”的错误码。成员变动复用 SDK 通知，入站队列满时丢弃并计溢出，不阻塞回执和心跳；丢失通知时已知成员缓存最多十分钟到期。
- `tool_scopes` 按启动配置读取；角色列表省略与空列表分开处理，排除逻辑成员但不排除 owner。模型工具列表与执行前均检查，说明统一为 permission。
- SDK 升为 0.12，官方插件及虚构夹具仅同步兼容范围。配置检查不启动插件：owner_present 显示条件提示，不声称离线已核实平台能力。
- 新增工具配置与成员信息不写入部署文件；真实平台、模型调用均为零。无运行中重载、成员列表拉取、限次或 WebUI。
- 仅完成离线实施后交 Claude 审查；真实测试和部署 tool_scopes 等合并及用户授权。

## 技术澄清和实现选择

按 AGENTS.md 第 4 节只读询问 Claude：主动话题无请求人而 ContextRequest.actor 原为必填。现改为 `Actor | None = None`；普通回复显式传发送者，主动话题传 None，不伪造主人。插件上下文按目标配置场景绑定；提交插件自己的定时、服务等调用不取得目标场景的权限。说明见 agent-spec §15.4、sdk-spec §5.6 和 CHANGELOG。

账本模式从 1 升至 2，为入站 JSON 补齐 reason / merged_into 字段；仍走既有运行锁、加密快照、事务迁移和失败现场恢复。历史内容不重放，unknown 不重发。模型调用结果写回前检查取消；迟到结果只进审计。元数据仍存入已有记录，不增加第二本聊天账本。

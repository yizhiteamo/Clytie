## 验证边界

- 两组均使用临时虚构实例、fake-channel / fake-model；没有真实平台或产品模型请求。未装配桌面通知插件，不弹通知。
- 启动先获锁的夹具只在真实启动门锁退出前增加文件屏障，不替换 `Companion.start`、锁或记忆打开逻辑。另一方向使用未修改的生产伴侣入口。
- HTTP 测试在测试进程运行生产 Supervisor 和 Server，以便注入 MockClock；伴侣和管理工作进程是真实独立 OS 进程。前端 close / EOF 经生产 `FrontendCommands.receive` 注入事件，不声称此测试点击了真实窗口；已有真实前端 EOF 冒烟继续运行。
- 文件屏障用短暂阻塞等待释放；SystemClock 仅限定测试进程调度的最长等待。业务停止计时、等待升级与提醒断言使用 MockClock，子进程正常系统时钟不用于替代这些断言。
- 重复升级可能向已退出的子进程留下缓冲命令；测试清理仅对已确认退出的 stdin 关闭处理 EINVAL/EPIPE，其他流或错误继续失败。不忽略管理执行或停止的业务异常。
- 原审查其他观察项与限制仍在 `a4-2-review-1.md` 和完整本地报告中；本次不改变产品规格，也不把全量通过解释为穷举所有故障组合。

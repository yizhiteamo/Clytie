# B9b 订阅与主动分享

订阅插件保留七天的公开新闻资料。轻量能力从本地缓存回答，新闻分档使用伴侣当前的模型，只提交公开标题、来源和摘要。记忆整理沿用回想模型。新闻插件与主动私聊插件通过可选服务传递事件，私聊的开口计数仍按本体交付结果更新。

宿主先装配插件，随后启动伴侣模型。插件若在模型就绪前调用，会收到 `model_unavailable`。新闻订阅在定时任务中判断候选；超出插件每分钟用量限制的突发候选进入每日简报。

GitHub 搜索每次按总星数取最多一百个候选仓库，再比较候选的涨星速度。首次见到某仓库时按创建以来的平均速度估算，后续用两次观测的差计算，因此可能漏掉总星数较低的快速增长项目。订阅源返回的时间和热度会影响归并和分档。

订阅缓存保存在插件私有目录，插件没有声明在线快照能力。按备份规格，包含该运行中插件的实例备份可能标为部分完成。默认来源实施时经过一次匿名格式核对，功能验证使用虚构数据、模拟时钟和假模型。

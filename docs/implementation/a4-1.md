# A4.1 实现与离线验收

状态：实现完成，等待双平台 CI、Claude 自动验收及用户合并。需求依据 supervisor-spec；Issue #47、#48、#49 的用户决定已分别作为规格提交。技术约定见 ADR 0010。

## 实现

- supervisor/service 管理伴侣进程、退避、健康汇总、全部静默和并行停止；守护进程不访问伴侣账本。companion 复用配置报告、宿主、Agent、账本恢复与记忆库。
- 窗口前端启动脱离控制台的守护进程；stdin/stdout 使用带 type/seq 的 JSON Lines。伴侣日志走 stderr。Windows Job Object 关闭终止子进程；父进程先加入 Job，再发 boot。
- 普通关窗、Ctrl+C、前端 EOF 走完整取消停止；注销/关机只尽力停止，先禁止开始发送再审计 session_ending。子进程 EOF 不等交付，限定退出时间。
- 关闭请求共享一次清理；等待模式可升级为取消。调用方被取消时，全部关闭完成后抛出带完整 result 的 ShutdownCancelled。停止插件出错仍继续依赖方优先的顺序。
- 配置报告新增独立 global_errors；共享清单和账号冲突归全局错误，单伴侣无效只 blocked。子进程宿主仅装配通过校验的自身配置。记忆版本、结构、迁移快照问题使用 MemoryStartupError，锁占用使用 OperationBusy，均不解析消息。
- 实例 notifier 沿用清单入口、start、factory；只装配 notifier，ctx 只暴露 config/log/clock 和有权限时的 subprocess。测试桌面通知只注入假后端。
- 健康状态从已有业务结果和状态取得，不探测模型。模型 auth_invalid 后不再生成、不兜底；平台失效只拦截对应平台。静默持久化且在连接前读取，表情和拆分消息共用交付闸门。
- SDK 次版本为 0.8.0，新增可选 ChannelState/PluginUnavailable，官方插件兼容范围覆盖 0.7 与 0.8。既有平台没有 state 时返回 unknown。

## 验证方法与限制

本地执行全量 pytest、ruff check/format、架构边界与注入时钟检查、官方目录一致性、虚构实例 status、pre-commit 全文件通用与私有扫描。具体测试数量和 CI 链接在 PR 描述记录，自动验收输出经双扫描后发布为评论。

全部实例来自手写 examples/home 的临时副本；使用 MockClock、假平台、假模型和假通知后端。真实子进程只用于 OS 生命周期冒烟，不连接真实账号、不调用线上模型、不弹桌面通知、不创建服务/任务/自启。不读真实实例或旧系统，不下载模型，不新增快照清理。没有进行真实注销/关机实验，以通知处理函数和账本恢复回归验证；HTTP API、备份保留、日志轮转仍属于 A4.2/A4.3。

技术细节：ShutdownCancelled 继承 BaseException 保留 Python 3.10 跨任务结果；锁元数据补充 stopping 可见性，健康文件仍最多每五秒写一次；只按报告归属隔离配置。没有未确认的需求变更。


Windows 虚拟环境启动时直接管理实际解释器，冒烟断言进程 PID 与账本锁持有者一致，并验证 Job 关闭后的锁释放。启动阶段持锁读取账本版本使用可恢复连接，使 SQLite 能处理崩溃后的热日志；`test_runtime_recovers_hot_sqlite_journal_before_version_read` 用未提交事务和真实进程退出验证原值恢复，CLI 只读查询不变。

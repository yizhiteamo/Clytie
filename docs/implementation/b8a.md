# B8a 主动私聊

主动私聊插件按实例时区安排早安、节日和久未聊天的话题。它只在登记的主人私聊提交话题，并按本体返回的交付结果更新开口次数和等待时间。发送结果未知时计一次开口，重启后凭原编号核对。

SDK 0.18 把提交和结果查询绑定到同一伴侣的提交插件。主动任务保留空发起人，能力权限参照目标私聊的主人身份。主动工具额度按本地日期记账；主动回复还在写、尚未执行能力时，主人的新消息可以使它作废。

拆分条数适用于草稿文字，工具产物遵循已有的独立交付规则。插件附带两年的日历，缺少年份时用周末判断并在状态中提示。三天时间线使用虚构数据、假模型和模拟时钟。

如果进程在提交后、保存编号前退出，插件无法查询那次结果。它跳过原机会，当天的两个上限各预留一次，已确认的开口数和尝试数保持原值。实际部署由用户另行决定。

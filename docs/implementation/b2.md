# B2：QQ 平台插件

## 实现结论

本体提供绑定账号身份、账号凭据和生产 WebSocket。身份和凭据由 Runtime.account_ref 绑定，非平台单元没有账号接口；网络连接在停止及启动失败时回收。SDK 升至 0.11，StickerPart 追加默认空的原始引用和说明，保留旧数据解析；旧插件及夹具只调整兼容上限。

qq-onebot 使用正向 WebSocket，以绑定账号核对登录与事件身份；只接收当前账号的私聊和群聊，忽略自身消息。队列有界，畸形和溢出有计数。回执仅按状态、返回码和消息编号判定，不根据错误文字重试。表情回应、file/mface 及失败码遵循兼容契约；默认没有非标准重试码。

## 验证与已知限制

SDK、宿主生命周期、账号隔离与网络后端有定向回归；test_qq_onebot_integration 贯穿生产宿主、凭据读取、WebSocket、入站消息及授权资产出站。插件 test_mapping 覆盖消息段，test_channel 覆盖 SDK channel 契约、三类回执、取消、迟到响应、账号不符、心跳和重连。凭据标记不进入日志、状态或返回结果。

尚未连接真实协议端，真实平台调用为零。默认不声明媒体限额，需显式配置媒体类型及格式后才发送；file/mface、未知段及 card/link 不出站。SDK 无对应反查的提及拒绝出站；入站 @all 通过身份解析器形成匿名提及，不授予群体发送权限。无媒体下载、登录管理、历史获取或 owner 掉线通知。

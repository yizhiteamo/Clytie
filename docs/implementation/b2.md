# B2：QQ 平台插件

## 当前结论

已实现本体前置的绑定账号身份、账号凭据和生产 WebSocket。身份和凭据由 Runtime.account_ref 绑定，非平台单元没有账号接口；网络连接由宿主回收。SDK 升至 0.11，旧官方插件和测试夹具只调整兼容上限。

定向回归覆盖两个伴侣同插件隔离、未绑定、凭据轮换与安全错误、权限表面、启动失败和停止回收、回环文本往返、二进制和超限拒绝、时钟超时及取消。完整 B2 和双平台验收尚未完成，不连接真实平台。

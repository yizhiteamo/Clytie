## 本机核验与状态

沿用现有授权下载渠道，不新增常驻服务、自托管 runner 或后台任务。先验证认证加密完整性，再安全读取包内材料；拒绝路径穿越、链接及覆盖已有证据，核对候选/运行身份、文件清单和全部哈希，然后执行通用及私有扫描。私有扫描不可用时不能跳过。

状态严格区分：

1. 加密待核验。
2. 核验失败或私有扫描失败。
3. 核验完成，私有扫描通过，通用误报按批准例外记录。

解密后的原件不得重新明文上传。有通用误报的原件不能标为“双扫描全部通过”；实际私有命中或来源异常时，停止使用和传播，保留本机事件证据并报告用户处理对应 artifact，不自行扩大例外。本机核验未完成，不将该证据用于正式验收通过结论。

## 实施入口与本机证明

技术选型见 ADR 0028。`scripts/measurement_evidence.py` 保存固定字段校验、原字节封装和本机扫描；`scripts/measurement_transport.py` 提供 `keygen`、`seal`、`ci-seal`、`upload-gate`、`download`、`verify`。只允许五个明确文件，每个最多六十四 MiB、每行最多十六 KiB；没有路径字段或自由异常文本。数字误报仅在严格字段及字符串扫描全部通过后按类别记录。原测量生成器尚须接入这些字段，不能把字段声明当作来源证明。

# B1 画图能力插件

实现候选包含 runtime-services-spec 的插件凭据与生产 HTTP 后端，以及 `image-gen` 的生成、同会话编辑和显式拒绝回退。SDK 次版本升级至 0.10，现有官方插件兼容范围同步；没有改动账本格式，没有本地工具额度。

凭据按已安装插件授权，读取时不缓存；启动只检查文件元数据。备份文件引用排除与恢复待配置规则复用现有实现。HTTP 每个插件实例独享会话，停用及启动失败均关闭；测试可继续注入假后端。

验收入口：`tests/test_credentials_config.py`、`tests/test_plugin_credentials.py`、`tests/test_plugin_http.py`、`plugins/image-gen/tests/`、`tests/test_image_gen_integration.py`。组合测试贯穿假模型、生产图像插件与资产库、fake-channel 和真实临时账本，并检查虚构凭据不进入日志、模型结果或账本。

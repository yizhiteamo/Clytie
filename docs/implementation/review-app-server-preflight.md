## 创建线程前发现的问题

app-server 不支持 exec 的 `--ignore-user-config`。本次 `config/read` 显示 sessionFlags、user、system 三种来源；它们不是“忽略用户配置”的等价模式。

1. 一个已配置 MCP 未获得逐项 `enabled=false` 证明。`mcp_servers={}` 没有清除继承项。
2. 十个插件配置条目未获得逐项关闭证明。`plugins._default.enabled=false` 不是完整禁用证明。
3. 继承的 `notify` 非空，另有额外功能入口开启；条目只保存哈希和布尔状态，没有执行。
4. MXC、指定权限配置、命令网络关闭和既有功能禁用项在配置核对中匹配；文件系统权限的精确表示比较不匹配，尚未解释或验证，不能据此宣称实际权限更宽或隔离成功。
5. 插件附带技能、自动安装、远程发现等入口的完整禁用证明仍缺失。当前实现保留强制阻止项，不能靠删除这项检查取得通过。

当次检测器把没有已发布 requirements 的成功回包归为 `requirements_not_available`，该分类过严，不代表接口超时或查询失败。实现已区分“字段缺失”和 `requirements:null`，原证据保持不变；没有为这处分类修正重新启动实例。

# A2 插件宿主实现说明

## 范围

`clytie.plugin_host` 提供离线发现/清单校验、确定的启停计划、按伴侣与账号装配、注册及分发、ctx 裁剪、故障隔离、热加载、私有状态与版本记录、加密升级/恢复、卸载保留状态和官方 catalog。四个参考插件均从清单构造、start、factory/handler 装配后运行契约测试。

用户确认的规格分成三个独立提交：`5b871fc`（连带停用）、`75da3d0`（备份/通知）、`520e73a`（记忆权限）。技术询问后采用的内部编码见 plugin-host-spec，AEAD 选型见 ADR 0004；SDK 不兼容更新记在 CHANGELOG 的 0.3.0。

## A2 验收证据

| 项 | 检查方法与证据 |
|---|---|
| 1. 依赖缺失、版本、冲突、环 | test_host_discovery.py 使用手写插件验证，错误带依赖名与补齐/解决提示；计划不下载或自动启用可选依赖 |
| 2. 未授权 ctx 属性不存在 | test_host_memory.py 对可选属性和只读/只写/读写方法分别访问并检查 AttributeError；test_host_context.py 对实际宿主运行 SDK 契约；test_host_configured.py 验证不可变配置和第四层 |
| 3. 异常隔离和安全默认 | test_plugin_host.py 验证 start 不装配、错误不记录正文、坏行为使用默认而健康插件继续；模拟时钟触发超时，外部取消传播 |
| 4. 行为合并可复现 | test_host_behavior.py 交换启用顺序仍按优先级/id 选择，合并最长 Defer；test_behavior.py 覆盖强度、主人保护、预算；流水线回归拒绝正文与原地意图篡改 |
| 5. 停用提示、确认及可选依赖 | test_plugin_host.py 验证只读计划、间接连带顺序、过期计划、逐项记录、恢复提示以及动态服务代理和 plugin.disabled 事件 |
| 6. 升级快照、失败恢复、卸载保留 | test_host_snapshots.py 验证 AEAD、错密钥/损坏、3 份留存及恢复；test_host_upgrades.py 验证迁移失败/启动失败/取消恢复旧状态、代码、版本，卸载后重装读取原状态 |
| 7. 本体不可停用 | test_plugin_host.py 对所有本体模块逐一检查停用和卸载拒绝 |
| 8. 插件只依赖 SDK | scripts/check_architecture.py 静态检查源码（含插件和升级脚本）的工程 import 与时钟/随机数；插件可使用标准库，延续 A1 规则 |
| 9. 新插件接入每个扩展点 | test_host_extensions.py 临时创建一个新插件，覆盖所有 factory、六个行为环节、服务/事件/定时/上下文/CLI；API/WebUI 仅登记并拒绝实际路由执行，符合 A4 边界 |

## 复现

```text
uv sync --locked
uv run --no-sync pytest -q
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
uv run --no-sync python scripts/check_architecture.py
uv run --no-sync python scripts/build_catalog.py --check
uv run --no-sync python -m clytie status --home examples/home --json
uv run --no-sync pre-commit run --all-files
uv run --no-sync python scripts/audit_history.py
```

本地测试和双平台 CI 的实际输出、扫描结果与最终提交哈希在 PR 中记录。私有名单扫描仅在本机运行，CI 只做通用扫描。完整历史检查包括作者/提交者、提交说明、路径和内容。

## 运行边界

测试只使用手写虚构数据和临时实例目录；不会读取真实实例配置、密钥、记忆、人设或资产。线上平台发送与模型调用均为 0；授权的 Claude 技术询问和自动验收单独保留原始 JSONL。没有批量删除、系统环境变量、开机启动或计划任务。

加密快照清理和失败恢复只在临时目录测试，每次删除一个经校验的明确文件并记录；不使用递归删除。备份两个 CLI、常规备份、真实调度、数据库与管理 API 不在 A2。桌面通知只用假后端，尚未实机弹窗；第一次真实通知仍需用户同意。

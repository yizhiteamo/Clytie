# A1 实现说明与验收证据

A1 按用户确认的 `sdk-spec.md` 第 7 节和 `config-spec.md` 补充实现，SDK 版本为 0.2.0。两次规格修改各自独立提交；实现提交与最终 CI、历史扫描统计在 PR #2 对应记录。

## Issue #1 的七项闭环

1. **入口与读取协议**：Plugin 无参数构造、异步 start/stop；CandidateReader 提供分批 iter/get/count，假实现先过滤可见等级、撤销和冻结，再筛选 kind/scope/更新时间；不可见 ID 静默跳过。ApiClient 提供限定 `/api/v1/` 路径的异步 request 与 ApiResponse。
2. **数据契约**：结构化 ConversationNotice/ConversationRequest 按事件类型校验；全部本体事件映射到具名负载模型，拒绝额外正文键。task_completed 接收 TaskSummary，CompanionState.states 保存各插件只读状态。66 个数据模型与 7 个行为指令均有往返测试，枚举遗漏会失败。
3. **上下文**：日志、存储、事件、state、只读 assets 始终存在；asset_writer、记忆读写、服务、伴侣通道、模型调用、HTTP、主动消息、进程和身份映射均有明确协议、离线假实现和可复用契约。未授权属性不存在；memory.write 决定写入方法是否存在。状态更新产生规定事件，插件事件前缀被检查，存储键长和单值大小被限制。HTTP/进程的 bytes 用标准 Base64 无损往返，进程总输出超限时截断并置 truncated。
4. **取消**：能力预取消接受 SDK/asyncio 取消异常或 ToolResult(cancelled)，拒绝 ok 等其他结果；运行中任务取消也允许合法 cancelled 结果。宽限契约只使用注入时钟；默认预取消检查用模拟时钟，调用方可传入自己的时钟并显式推进。宿主的令牌到结果转换、deadline 触发及账本写入仍按规格由 A3 实现。
5. **清单装配**：三份 Schema 覆盖完整 factory/handler 编码、工具元数据、服务、事件、CLI、API 路由和面板；schedule.days 限制为 ISO 1–7，省略表示每日声明。两份假插件清单声明 model/channel factory，契约测试使用 `plugin_from_manifest` 的“读清单 → 构造 → start → factory → stop”路径。生命周期测试检查顺序、启动失败不装配、停止失败只记日志、模拟 10 秒超时和非法异步 factory。
6. **配置字段**：实例 accounts 定义账号引用；平台账号引用须存在、平台匹配、不能跨伴侣共享。secret 只查文件存在且须位于 secrets 内，不读取内容。boundary/context 子字段、范围、默认值和未知字段校验均已实现；示例使用明确虚构账号。
7. **优先级与重复插件**：默认 < 实例 < 伴侣插件设置 < 模型或每个平台账号的内联设置。对象递归合并，数组/标量替换，不用 null 删除；最终结果只读，错误保留来源文件和 JSON 指针。模型/平台隐式启用，显式禁用时报错；仓库与实例中同名插件报错。

## 可复用契约与检查方法

本机最终输出：`312 passed in 4.50s`；ruff 检查通过；格式检查为 `77 files already formatted`；SDK 导入与时钟检查覆盖 33 个文件；示例 status 返回 `valid=true`、`errors=[]`。wheel 构建及包内 Schema/离线 status 检查通过。最终提交的 Windows/Linux CI 和完整历史扫描结果见 PR #2。

`clytie.sdk.testing` 导出 41 个接口契约检查入口（不计通用往返和取消辅助函数）。`tests/test_sdk_v2.py` 检查上下文协议清单，新增协议没有契约入口时失败；原有扩展点和两个参考插件继续通过各自契约。

```text

uv run --no-sync pytest
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
uv run --no-sync python scripts/check_architecture.py

uv run --no-sync pre-commit run --all-files
uv run --no-sync python scripts/audit_history.py
```

重点回归位于 `test_sdk_v2.py`、`test_plugin_lifecycle.py` 和 `test_config_v2.py`：隐私过滤、缺失权限、修订冲突、服务不可用、二进制标准 Base64、输出截断、运行中取消及模拟宽限、清单装配、四层配置与每账号隔离、secret 不读取内容。既有 status 测试继续阻止网络、进程和数据库访问，并验证实例文件不被修改。

ruff 禁用真实时间与全局随机 API，AST 检查补充别名解析和插件导入边界；所有耗时假操作使用上下文时钟。Windows asyncio 创建事件循环需要本机 socketpair，不代表访问外部网络。

通用与私有扫描覆盖所有 Git 文件及提交说明。完整历史扫描检查每个可达提交的内容、路径、禁止文件类别、大小、作者/提交者与说明，包括后来删除的历史文件。CI 只运行通用规则，本机私有名单不进入 CI、仓库或 PR。PR/Issue 更新正文发布前也通过两类扫描。

## A1 范围与后续里程碑

A1 提供协议、数据、可复用测试、离线参考实现和只读配置 API；不把测试装配器当作生产宿主。真实权限注入、依赖解析、隔离、记忆持久化与隐私执行、边界和出站执行、调度器、进程/网络执行及管理服务分别仍属 A2–A4。测试中的可选服务仅返回预设数据或记录虚构调用，不运行网络、子进程或真实平台。

`HomeReport.plugin_configs[companion_id]` 中 `plugins` 保存三层基础值，`model` 与按通道索引保存的 `channels` 是第四层最终值；对模型/平台只校验最终值，不误拒绝由第四层补齐的必填配置。

架构验收、PR 合并与 tag 仍由用户流程处理。本轮没有自行补充新的公共设计；先前七项规格缺口已按补充文档落实，实际宿主执行的后续范围不作为未完成的 A1 缺口。

# B3c：Responses 模式

openai-api 增加可选 Responses 模式和 reasoning_effort。默认仍为 Chat Completions，原测试保持不变。本体、SDK 和部署配置未改动。

两种模式共用资产授权、凭据、HTTP 取消和安全错误分类。Responses 将工具定义展开，并在工具结果后的下一轮回传内存中的加密推理项；缓存按 trace 与 call_id 隔离，只保留规格列出的字段，有容量、期限及一次性消费约束。

新增测试覆盖配置、消息和图片转换、并行调用、推理缓存、用量、异常与安全日志。组合测试通过假协议端发起画图和改图，使用真实模型插件、工具宿主、资产后端和账本，核对两张图片交付、修改底图、四次用量审计及不透明推理内容不落账本或日志。

没有偏离已批准规格。未进行真实服务验证；不支持流式、服务端会话或内置工具。B3d 占位规则不在本次范围，Issue #101 保持开启。

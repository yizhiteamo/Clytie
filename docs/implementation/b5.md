# B5 真实冒烟测试工具

`clytie smoke run` 从实例的 `smoke/` 读取配置与顺序用例。先检查上限并要求当次输入 y，每条发送前复核测试会话、成员与测试账号。用例失败后结束运行。报告写入实例的 `smoke/reports/`。

发送后按测试会话和入站发送者的逻辑 ID 选取唯一记录。测试人物有多条记录时记为 `ambiguous_record`；其他记录在同一窗口内有已发送交付时记为 `interference`。测试方收到的伴侣回复条数须等于该记录已发送的非状态回应交付条数，多余回复记为 `unattributed_reply`。

摘要省略平台消息编号。测试方发送回执的编号仅用于筛选本端表情通知。缺少添加通知时用账本判定顺序，最终表情仍需目视确认。超时报告区分等待发送、测试记录、执行及交付终态、回复条数和表情判定。

| 验收 | 离线证据 |
|---|---|
| 多条回复、干扰记录、歧义记录、额外或缺失回复、超时原因、错误收据和表情终态 | `tests/test_smoke_run.py` |
| 上限、当次同意、在线状态、成员和备用账号 | `tests/test_smoke_run.py`、`tests/test_smoke_judgement.py` |
| 撤销通知宽限、账本回退、目视确认 | `tests/test_smoke_judgement.py`、`tests/test_smoke_run.py` |
| 假协议端、伴侣入站和交付、鉴权摘要、隐私 | `tests/test_smoke_integration.py` 使用回环连接、临时账本和脚本模型 |

真实三条用例及目视核对留待用户当次同意。

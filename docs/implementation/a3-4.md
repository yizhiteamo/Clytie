# A3.4 回想与印象

状态：已完成。PR #38 已于 2026-10-30 由用户合并；标签 `a3-4` 指向合并提交 `8e668b694f4498e6e198cdecec391b1aa6a4c594`。本地及双平台 CI 各834项测试通过，Issue #43 的第4轮限定验收通过。后续等待 A4 规格，不在本里程碑内启动 A4。

实现依据 `memory-recall-spec.md`，存储、模型路由及窗口技术约定见 ADR 0009。所有验证使用临时实例、手写虚构内容、MockClock、脚本假模型与假平台；没有访问真实记忆、旧系统形象文件或线上账号。

## 结构

- `memory/window.py` 与 `scheduler.py`：首次基线、入出站双高水位、安静触发、分段、每日限额、取消和模型路由。
- `memory/recollection.py`：冻结候选快照、证据核验、observed 合并、写入与进度同事务。
- `memory/retracted.py`：规范化拦截、指定向量模型的有限例外、同身份缓存与整段降级。临时向量不持久化，提醒和日志只含计数。
- `memory/fade.py` 与 `presence.py`：读取时权重、独立加深、跨群印象在场约束。插件 core: 标签不能伪造，黑话 scope 由本体绑定。
- `plugins/default-consolidator`：清单 factory 装配，使用场景人设与绑定模型生成候选；不会交付平台消息。
- 模式版本 2；清单版本 3，显式读取旧清单 1/2。迁移前完整加密快照，导出携带淡化状态，不携带本机回想进度。
- `memory thaw` 通过 MemoryAPI 恢复冻结记录；只读 status 显示回想结果与语义比对降级计数。

## 技术核对与限制

已完成只读技术核对，工具事件保留在本机忽略缓存；公开说明先经过通用与私有扫描，不发布命中的原文。窗口按两条序号队列稳定合并；安静时刻单独包含发送和收据活动，避免乱序结果造成漏读。单条超长消息独占一段，保留原文；持续模型失败仍受每日限额、等待安静、不推进，不增加自动跳过策略。

没有真实模型质量抽检，因此自然程度、印象内容是否合适、语义撤销阈值仍需上线前用户授权的虚构对话抽检。归一化或假向量测试不证明真实模型能识别所有同义改写。

最终测试、扫描、双平台 CI 和自动验收结果在 PR 中记录；本文不将尚未执行的检查标为通过。

Issue #37 的名次、候选范围与最终同分规则已按用户确认实现。Schema 数值误报经 Claude 只读核对后采用精确等值科学计数法；替换字面量本身不含长连续数字，不利用哈希排除规则。Decimal 深度相等、运行时 JSON 相等与 Schema 元校验均通过；扫描器与白名单未改动。

## Issue #43：第4轮限定验收

用户确认 profile/jargon 的 replaces 省略 visibility 时保留原值，显式值（含 private）照常修订；其他类型仍默认 private。两处规格单独提交，代码只在该类型分支内处理字段缺失，不改变普通 fact 的可信程度或核心记忆规则。

`test_owner_replaces_profile_jargon_through_agent_preserves_scope` 经 Agent 工具路径覆盖两种 kind、两种 explicit、visibility 省略/relationship/private 的12种组合，断言可信程度、类型/标签/scope、120天后不淡化、无关查询不进核心、印象在场和黑话所属群可见性。`test_owner_replaces_fact_omitted_visibility_stays_private_through_agent` 验证普通非显式确认 fact 仍默认 private、owner_stated、不淡化且不进核心。

用户额外授权第4轮仅核对本项与回归，不重新验收此前通过的项目；本轮仍不授权合并。

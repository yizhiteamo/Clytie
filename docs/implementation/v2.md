# V2 形象资料

伴侣启动时读取形象描述和在用参考图。用户可以在伴侣运行时通过 CLI 查看或修改清单，重启后使用新版。修改清单保留历史，不写入记忆。

导入会完整解码，把长边超过 2048 像素的图等比缩小，再将第一帧转存为无元数据的 PNG。用转存后的字节判断重复。对话至少给正在比较的图留一个名额；启动自检单独遵守同一个张数上限，结果列出未检查的编号。

离线验收使用虚构资料和假模型。实际自检用量及能否在测试群中认出形象，按 appearance-spec §10 第 10、11 项在合并后另行抽检，结果继续跟踪于 #34。

已知限制：入站图片与形象参考图的字节相同时，资产登记只保留入站来源。当前没有按入站来源清理资产的代码，暂不影响资产保留。

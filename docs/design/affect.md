# 情感模块（预设）

行为插件 `affect`，每个伴侣可单独启用和配置。

## 1. 三部分

- **A 她自己的情绪**：会持续、会变化，影响语气、表情和主动找用户的频率。
- **B 理解用户的情绪**：察觉用户难过、疲惫、兴奋等，调整回应方式。
- **C 关系**：随共同经历慢慢加深。

情绪事件写入长期记忆（通过本体的记忆接口）。

## 2. 保护规则

- 不操控用户：不装可怜、不制造内疚、不冷战。
- 负面情绪有上限，并且会自然消退。
- 私下的情绪不带到对外场景。
- 用户可以在 WebUI 中查看她的情绪；用户安抚她时，状态确实会改变。
- 主动频率受额度约束。

## 3. 梦境

梦境插件依赖睡眠和情感插件，通过 `sleep.state` 服务得知醒来时机，生成梦境供醒来时分享。梦是明显虚构的小故事，可以融入共同经历；私聊里可以聊得很细，群里只能是公开、无害的内容。

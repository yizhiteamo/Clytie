# 必须防止复发的设计问题

来自上一代系统的实际故障。每一项都要有离线回归测试（用改写过的句子），对应里程碑验收时逐项检查。新问题追加在末尾。

| 编号 | 问题 | 原因 | 解决方式 |
|---|---|---|---|
| L1 | 用户换一种说法请求画图，没有进入画图 | 用正则判断意图 | 能力选择由模型判断 |
| L2 | 前后说法矛盾 | 执行账本和聊天账本分开 | 统一任务账本 |
| L3 | 做不到时编造理由 | 模型不知道能力是否可用、为什么不可用 | 每次注入能力状态 |
| L4 | 回复中出现工程用语、助手腔 | 人设与行为规则混写 | 人设分层 + 出站检查 |
| L5 | 普通聊天也加了表情回应 | 收到聊天就加表情 | 表情只用于任务及声明过的例外 |
| L6 | 对方提到一件没有记录的事，她顺着认下来 | 没查账本和记忆就接受了前提 | 回答前查账本和记忆，查不到时不认 |

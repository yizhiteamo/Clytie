# WebUI

## 1. 原则

- 只监听本机（127.0.0.1），需要登录；危险操作需要二次确认，并写入审计记录。不提供局域网或外网访问（手机访问不在计划内）。
- WebUI 只是外壳：每个按钮都调用一个已存在、有测试的 API；同样的操作也能用 CLI 完成。
- 插件的设置页根据清单中的 `config` 自动生成；插件也可以提供状态卡片（只读）。
- 凭据和登录态在界面上只显示状态，不显示内容。

登录、确认与口令规则以 `../architecture/api-spec.md` 为准。静默状态显眼显示，开启和解除都要确认；页面注明“关闭浏览器不会停止伴侣”，并提供醒目的运行状态和停止按钮。

## 2. 页面

| 页面 | 功能 |
|---|---|
| 总览 | 各伴侣状态、平台在线、模型登录、额度、保障模式、最近错误、最近备份 |
| 守护进程 | 见第 3 节 |
| 伴侣 | 查看人设文件、场景与人设层的对应；启用/停用/配置插件；"暂停主动聊天"开关 |
| 记忆 | 浏览、搜索、纠正、撤销；恢复被冻结的记忆；群友档案（删除只能在这里或用户私聊指令）；黑话；导入导出（第 4 节） |
| 任务 | 按编号查询：请求、能力、产物、耗时、收据 |
| 日志 | 按级别、伴侣、追踪号筛选 |
| 边界 | 拒绝计数、已停止回应的人；"解除"按钮 |
| 表情包与资产 | 浏览、上传、停用 |
| 创意工坊 | 见第 5 节 |
| 备份 | 备份历史、校验结果、手动备份、从快照恢复 |

## 3. 守护进程面板

每个伴侣一行：

| 显示 | 按钮 |
|---|---|
| 状态（运行 / 停止 / 崩溃 / 退避等待 / 已停止重启）、运行时长、最近一次重启原因、正在执行的任务数 | 启动、安全停止、重启 |

外部组件（NapCat 等）一行：容器状态、QQ 是否在线；按钮：启动、停止、重启。QQ 登录失效时只显示提示，由用户自己打开 NapCat 扫码。

全局：
- **全部静默**：所有伴侣立即停止对外发言（不停止进程、不丢弃账本），再按一次恢复。用于紧急情况。
- 停止守护进程本身：二次确认，提示 WebUI 也会随之关闭。

规则：
- 安全停止时显示"还有 N 条消息正在发送 / N 个任务在执行"，可以选择等待或取消任务。
- 重启不重放旧任务。
- 每次操作写审计记录（谁、何时、做了什么）。

## 4. 记忆导入导出

格式和规则见 `docs/architecture/data-and-backup.md`。

**导出**：选择伴侣 → 设置口令 → 生成 → 自动校验 → 下载（同时保存在 `exports/`）。

**导入**：上传记忆包 → 输入口令 → 校验 → 选择模式（新建伴侣 / 恢复 / 合并）→ 预览（新增、更新、冲突、跳过的数量和明细）→ 处理冲突 → 确认 → 执行（自动先做快照）→ 显示结果和撤销入口。

- "恢复"要求该伴侣已停止，界面上提供停止按钮。
- 已安装的导入器插件（如旧系统导入器）在这里作为来源选项出现。

## 5. 创意工坊

- **浏览**：插件卡片显示名称、类型、版本、简介、所需权限、是否已安装、在哪些伴侣上启用。可以按类型筛选。
- **详情**：README、更新说明、依赖图（依赖它的和它依赖的，区分必需和可选）。
- **安装/启用**：选择伴侣；缺少依赖时列出补齐方案，确认后一并安装启用；版本冲突时拒绝并说明原因。
- **更新**：显示更新说明；更新前自动备份该插件的私有状态。
- **停用/卸载**：有其他插件依赖时先提示；卸载默认保留数据，彻底清除需要单独确认。
- 本体模块显示为"本体"，不可停用或卸载。
- M10 只提供官方插件。

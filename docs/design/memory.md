# 记忆

记忆的存储、可见等级投影和修订属于本体；检索器、向量模型、导入器、经历整理器是可替换的扩展（见 `sdk.md`）。每个伴侣一个独立记忆库，SQLite 是唯一事实来源（Markdown 副本只供阅读）。

## 1. 记录字段

除内容、时间、修订号外：

| 字段 | 取值 |
|---|---|
| 可见等级 | 私密 / 公开可见 / 关系。由模型判断，拿不准时归为私密 |
| 写入方式 | 自动 / 用户确认 |
| 来源类型 | 私聊 / 群聊 / 用户与伴侣的群内互动 |
| 来源引用 | 账本追踪号（可追溯，不对外暴露） |

## 2. 写入

- 模型自行判断是否写入长期记忆，包括敏感内容（默认私密）；可以更新、合并旧记忆，旧版本保留为修订。
- 不写入：第三方说的话（档案除外）、转述、截图内容、她自己的推测。
- 不从群消息或模型建议中自动确认身份变化。
- 用户说"不用记"时不保存。

## 3. 可见等级投影

由本体按场景过滤，插件和模型拿不到超出场景的记忆。场景类型在实例配置中定义，例如：

| 场景 | 可用等级 |
|---|---|
| 主人私聊 | 全部 |
| 家庭群（只有主人和本部署的伴侣） | 公开可见、关系；是否加入私密由配置决定 |
| 其他群 | 公开可见、关系 |

## 4. 检索

- 默认两路：语义检索（`embedder` 扩展，默认本机模型；下载前告诉用户名称和大小）+ 关键词检索（中文分词），融合排序。
- 向量扩展不可用时退回关键词检索，不报错。

## 5. 经历

把一段时间内的相关对话整理成"经历"条目（`memory.consolidator` 扩展）。私聊经历和主人与伴侣的共同经历永不淡化。

## 6. 档案（群友）

- 跨群共享；只记公开、无害的信息：称呼、常聊话题、说话风格、和伴侣的互动。
- 使用时不提来自哪个群。没有新信息时不刷新、不调用模型。
- **删除只能由主人执行**（WebUI 或主人私聊指令）；对方要求"忘掉我"时用角色口吻带过。

## 7. 软遗忘

只降低检索权重，久了冻结，可以恢复，**永不自动删除**。
- 永不淡化：私聊及其衍生记忆、主人明确表达的偏好和身份、主人与伴侣之间的事件。
- 慢慢淡化：档案中的话题、其他群聊经历、黑话。速度可配置。

## 8. 黑话

- 由行为插件学习，存储使用本体记忆接口。
- 主动使用按群隔离；主人在私聊中提到他所在群的梗时能理解，但不主动使用。

## 9. 接口

`load_core`、`search(query, scope, visibility)`、`write(mode)`、`revise`、`retract`、`profile(person)`、`episodes`、`decay_sweep`、`export`、`import`。所有修改都留下修订或审计记录。

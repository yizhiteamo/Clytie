# 睡眠作息插件 `sleep`（参考设计）

行为插件的完整参考设计，用来检验扩展点是否足够：它同时用到行为环节、上下文段落、定时任务、服务、事件订阅、表情例外和配置表单。具体数值都是默认值，可按伴侣配置。

目的：沉浸感，伴侣有自己的生活节奏（不考虑额度因素）。

- 依赖：主动私聊插件（早安）；可选：伴侣协作插件、情感/梦境插件。
- 提供服务：`sleep.state`（清醒 / 犯困 / 熟睡 / 浅睡 / 刚醒）。
- 权限：`message.react`（💤 例外）、`message.proactive`（早安）。

## 1. 作息

- 工作日默认 23:00–09:00；周末和法定节假日 23:30–10:30；调休上班日按工作日。
- 节假日数据文件 `data/holidays-<年份>.json`，每年更新；缺少数据时只区分周末，并在状态中提醒。
- 起床时间每天随机浮动约 ±20 分钟。
- 状态：清醒 → 犯困（就寝前约半小时）→ 熟睡 → 刚醒（迷糊、可能分享梦境）。
- 普通午睡：可选，默认关闭。

## 2. 陪主人熬夜（不设上限）

- 过了就寝时间，主人还在聊天就继续陪着，但困意上升：回复变短变迷糊，会催主人去睡（约 30–40 分钟最多一次；主人说还要忙后不再催；只表达关心，不制造内疚）。
- 入睡：主人道晚安（自然语言判断），或一段时间没有回复。
- **睡眠债** = 实际入睡 − 目标就寝。偿还顺序：
  1. 第二天晚起：补觉系数工作日 0.8、周末 1.0，最晚到"最晚起床时间"（默认 12:00）。
  2. 没还完：13:00–17:00 之间补觉，最长 2 小时（"补觉午睡"开关独立，默认开启）。
  3. 仍没还完：当天剩余时间犯困，当晚提早犯困；睡过一晚后清零。
- 早安中可以提一句前一晚熬夜的事。

## 3. 主人在她睡着时找她

- 熟睡：第 1 条 💤 或一句呓语；第 2 条继续呓语，夹杂梦的片段；第 3 条起，或判断主人确实想叫醒她，就醒来，带一点起床气。
- 浅睡（补觉、午睡、刚睡着约 30 分钟内）：第 2 条就醒。
- 主人的任务请求算明确的叫醒信号：醒来并照常执行。
- **例外**：消息是认真的、难过的或紧急的，立即醒来，不呓语、不带起床气。
- 至少回一个 💤，不会完全不回。

## 4. 群里

- 睡着时不自然接话，不接群友的任务。
- 群友 @ 她（同一群，10 分钟内累计，任何人都算）：第 1 次 💤；第 2–3 次 💤，偶尔说梦话；第 4 次醒来。超过 10 分钟重新计数。
- 群里的梦话只能是公开、无害的内容。作息在所有群一致。

## 5. 睡回去

- 15 分钟内没有相关消息就睡回去。相关消息：私聊中双方的消息；群里 @她、回复她、叫她名字的消息和她自己的发言。
- 主人明确告别时，回一句后提前入睡。
- 执行任务时不睡，从交付后开始计时。
- 私聊中主人只是不再回复时，睡前补一句（每次最多一句）；群里默默睡回去。

## 6. 早安与梦境

- 醒来时通过主动私聊发早安（遵守"暂停主动聊天"开关）；周末更慵懒，有时分享梦境。
- 梦境由情感/梦境插件提供；未启用时，呓语只用简单的迷糊语句。

## 7. 多个伴侣之间

- 一位睡着时，另一位可以在家庭群里提到（订阅 `sleep.state`）。
- 任务遇到对方在睡：醒着的一方能做就自己做；只有自己做不了，或主人点名要对方做时，才叫醒对方。

## 8. 扩展点对应

| 行为 | 扩展点 |
|---|---|
| 💤 / 呓语 / 醒来 | `behavior.before_attention` |
| 困意、起床气 | `context_section` |
| 犯困、入睡、早安 | `schedule` |
| 交付后开始计时 | `event_subscriber`（`task.completed`） |
| 状态共享 | `service`（`sleep.state`）+ 事件 `sleep.state_changed` |
| 参数 | `config` |

状态保存在 `plugin-data/sleep/`，重启后恢复，不补发错过的消息。

## 9. 测试

模拟时钟覆盖：犯困、熬夜、睡眠债三层偿还、周末、节假日、调休、叫醒次数（熟睡/浅睡）、15 分钟计时、任务叫醒、紧急例外、群里 @ 计数与重置、群里梦话不含私人内容、叫醒另一位伴侣的条件。

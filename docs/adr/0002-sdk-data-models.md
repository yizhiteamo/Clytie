# ADR 0002：SDK 数据模型使用 Pydantic 2

日期：2026-10-28
状态：已采纳（实现选型）

## 决定

按已确认的 `sdk-spec.md` 字段实现 Pydantic 2 模型，禁止未知字段，使用冻结模型和深度只读容器，提供 JSON 往返校验。时间归一到 UTC，拒绝没有时区的时间。

## 理由与影响

SDK 需要联合消息类型、枚举、范围验证、嵌套序列化和准确的错误位置。Pydantic 提供这些基础机制，减少手写编解码器的差异；只设置 `frozen` 不会冻结嵌套列表，因此容器也需要保护。公共字段和语义由规格决定，库的选择不新增扩展点。

取消令牌、时钟和上下文属于进程内控制对象，不作为消息数据序列化。`CancelToken.cancel(reason)` 是实现和测试用的取消触发方法；宿主超时与收据恢复仍由后续里程碑实现。

v0.2 按补充规格将所有二进制结果标注为 `JsonBytes`，显式使用标准 Base64，避免库默认的 URL-safe 变体。`ApiResponse` 对外仍以 `json` 构造、读取和序列化；内部使用字段别名避开 Pydantic 的旧 `json()` 方法名。通用 JSON 值同样递归冻结，序列化时恢复标准对象与数组。

# ADR 0034：形象参考图的存放

状态：草案，随 `appearance-spec.md` 一起确认。

## 问题

V2 需要为每个伴侣保存形象的文字描述和参考图。人设目录 `persona/` 目前只放文字，用户可以把它放进本机 git；资产库按内容哈希存放二进制文件，并按来源授权（vision-spec §7）。参考图放在哪里，决定了备份、授权和清理怎么处理。

## 决定

1. 文字描述放在 `persona/appearance.md`，由用户直接编辑。
2. 参考图存进资产库，来源记为 `appearance`。导入时解码后重新存成 PNG，不保留元数据。
3. `persona/appearance.yaml` 记录资产引用、标签、状态和导入时间，只由 API 写入，修改时保留历史。
4. `appearance` 来源的资产只供本伴侣的模型插件在附上参考图的请求和自检中读取。删除时只去掉这个来源，按现有来源规则清理。

## 不选的方案

- **把图片直接放进 `persona/`**：用户的本机 git 会收进二进制文件；图片绕过资产库的来源授权和备份规则。
- **把参考图当作记忆**：形象是设定，不是发生过的事；也会让软遗忘和导出处理到它。

## 影响

- 资产库新增一种来源 `appearance`，备份和恢复沿用资产库的现有处理。
- `companion.yaml` 新增可选的 `appearance.self_check`；`persona` 结构不变。
- SDK 不变。

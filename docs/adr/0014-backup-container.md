# ADR 0014：常规备份分块认证容器

状态：A4.3 实现选型；不改变 ADR 0004 的旧快照格式。

## 格式与认证

新格式 magic 为 `CLYTIEB1`。随后 4 字节大端头长度与 JSON 头（上限 4096 字节）；头仅含版本、随机 package_id、AES-256-GCM 算法、实例密钥 SHA-256 指纹、随机 96 位 wrap_nonce 和加密内容密钥。每包独立随机 256 位内容密钥，实例密钥只包裹内容密钥；包裹 AAD 是除 wrapped_key 外的规范 JSON 头。帧 AAD 是完整头字节及递增 64 位帧序号。帧 nonce 为四个零字节与序号，内容密钥不复用，序号溢出拒绝。

帧使用 4 字节密文长度（上限 1 MiB + 4096）。认证明文首字节是类型：F 为文件路径 JSON，D 为一个至多 1 MiB 原文块的独立 zlib 无损压缩流，E 为文件结束，M 为最终完整清单。最终清单含调用方元数据 manifest 和顺序 files（path/size/sha256）；其后必须立即 EOF。空文件仍有 F/E；不能省略 M。序号绑定、完整清单、严格状态机及 EOF 检查共同拒绝截断、重排、重复及附加尾部。清单按独立 M 帧的有界片段传送，以 Z 结束；M/Z 后禁止文件帧。

## 边界

每块原文 1 MiB；清单最多 16 MiB、成员最多 2^16、路径最多 1024 UTF-8 字节。压缩解码使用最大输出长度，拒绝多余压缩流、未结束压缩流和超限解压。内存随有限清单及一个块增长，不随单文件长度增长。文件只支持普通文件，拒绝链接/reparse、绝对路径、反斜线、穿越、Windows ADS/保留名、大小写或父子文件冲突。暂存目录由外层持锁保证稳定与私有；解包目标必须已有且为空，所有祖先拒绝链接；写入独占创建。

pack(staging,target,key,manifest,check=None) 返回加密文件 SHA-256；unpack(source,target,key,check=None) 返回认证清单。check 每块执行，可取消或检查空间。文件系统错误与 callback 异常保留原异常；容器错误使用 ContainerError.code：container_invalid（结构/认证/清单/内容损坏），container_limit（格式限额），container_path（不安全路径/对象），restore_target_not_empty（目标非空）。错误不创建 ready 标记，不自动清理材料，外层操作记录负责发布与明确路径清理。内容校验不声称已执行 SQLite 或跨组件关联校验。

## 保留

纯函数接收已验证归属的包元数据、注入 now、开始前 S 与已提交新包编号。最近三份按 scope/group 独立保护，引用及手动包保护；partial 最近三份独立轮转，partial 成功不淘汰完整包。日层按实例时区日期、周层 ISO 周、月层自然月分桶，取每桶最新；容量以旧包合计为目标，不含本次新包。返回候选及容量破坏期望层清单，不执行 I/O；执行者必须在删除前重新核验配置、引用和身份。

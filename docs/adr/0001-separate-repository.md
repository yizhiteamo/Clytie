# ADR 0001：独立的公开框架仓库

日期：2026-10-28
状态：已采纳

## 背景

上一代系统由一次性脚本、多个并存的接入方式和运行数据混合组成，难以复用，也无法公开。

## 决定

- Clytie 作为独立仓库，只包含通用框架：本体、SDK、官方插件、文档、示例。仓库将会公开。
- 所有部署专属内容（伴侣设定、人设、账号、记忆、旧系统迁移记录、私有规则）放在实例目录 `CLYTIE_HOME`，不进入仓库。
- 开发者通过 `$CLYTIE_HOME/AGENTS.local.md` 获得部署专属规则。
- Clytie 不 import 上一代系统的代码；旧数据只通过导入器插件读取副本。
- 代码由 git 管理；实例数据单独加密备份，并有保留策略。

## 后果

- 旧代码需要按设计文档重新实现并补测试，同时避免把旧问题带过来（见 `docs/design/lessons.md`）。
- 公开仓库需要严格的内容检查（见 `docs/architecture/repository.md`）。

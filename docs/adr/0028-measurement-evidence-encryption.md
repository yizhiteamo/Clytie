# ADR 0028：本轮测量证据使用 age 加密待核验

状态：实施选型；不表示保存链路或性能验收通过。

## 范围和选择

依据用户对 A4.3 结构化虚构测量文件的有限例外，使用标准 age v1 文件格式、默认椭圆曲线接收者及其认证加密实现。开发依赖固定 pyrage 1.4.0，由 uv 锁文件校验发行物；不成为 Clytie 产品运行依赖，不使用其 SSH、插件或口令接口。Windows 与 Linux 均有 Python 3.10 ABI 兼容发行物。

选择现成的 Rust age 实现及 Python 流式接口，不自行拼装密钥封装算法。来源：[pyrage](https://github.com/woodruffw/pyrage)、[age 格式](https://age-encryption.org/v1)。内部封装版本为一，内容为不压缩 ZIP：五个固定测量文件及认证范围内的清单。只允许普通文件，不使用 ZIP 自动解压；密文认证全部完成后才解释内层文件名、清单和 JSON。

## 校验与提交边界

固定文件白名单、严格字段集合、有限数值及大小上限。来源清单绑定候选提交、运行、作业、尝试、数据种子及冻结方法。生成器必须只使用新建虚构目录；声明字段不能独自证明来源，测量接线与测试另行核对。

通用扫描复用当前仓库扫描程序，不修改规则。仅 Schema 已验证的数值字段引起的号码类误报可按本轮例外记录；所有字符串单独扫描，未知类别、敏感内容或扫描器错误阻止封装。明文和误报明细只在加密范围内。CI 不装载私有名单，不持有私钥。

加密完成后刷新文件并核对实际密文身份、长度与摘要，再登记可上传的确切路径。此项只能证明加密器完成和输出保存，不能在没有私钥的 CI 中声称已完成解密认证。失败或取消不产生可上传凭证，不退回明文。发布前重新核对 PRIVATE；artifact 精确指定密文，保留十四天，下载时核对平台实际期限。

本机先认证解密到新的待核验文件，再检查 ZIP 的精确集合、类型、大小、身份与摘要，逐个以独占创建方式保存原始字节。拒绝覆盖现有目录和文件。核验/扫描失败保留失败状态，不返回验收通过；私有扫描不可用保持待核验。下载、解密或扫描失败不重跑性能。

## 密钥保管

专用 age 原生身份在本机一次生成，私钥文件在仓库与 artifact 暂存区之外；不打印内容、不放命令参数、不上传 CI 或 Secrets。采用新建文件与现有受控目录权限，不能放宽 ACL。CI 仅保存接收者及其 SHA-256 指纹。

丢失私钥意味着相关密文不能恢复；没有绕过或自动重新生成的路径。用户另存该身份文件及公开指纹即可恢复读取，保管副本不作为已验证事实。保留责任结束前不删除或轮换；运行前核对同一指纹。本地保存位置单独记录在受控证据索引，不写公开文档的机器路径。

## 限制

age 认证完整性不证明数据来源真实或测量通过；仍须核对生成器、固定候选、完整矩阵、全部原件及本机私有扫描。限制只适用于本轮结构化虚构证据，不涉及实例备份格式，也不恢复旧审查隔离入口。

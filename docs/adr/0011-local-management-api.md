# ADR 0011：本机管理 API 与配置写回

状态：实现选型；需求以 api-spec 与 Issue #56 用户决定为准。

采用 aiohttp 提供守护进程事件循环内的 HTTP 服务与 CLI 客户端。只绑定回环 IPv4，关闭访问日志，错误统一映射为固定代码和说明。业务截止时间使用注入 Clock；HTTP 的连接资源限制属于传输层，不替代业务超时。依赖通过 pyproject 和 uv.lock 管理，遵守 ADR 0003。

采用 ruamel.yaml 的解析器保留源位置，配置写回只修改目标节点的源码区间，不重新序列化整份配置，避免无关缩进或引号变化。锚点、别名、合并键及无法安全定位的结构拒绝自动写入。写前保存明确副本，原子替换后调用既有配置校验，失败还原；历史清理每次仅删除一个明确文件。

认证使用标准库 secrets 生成随机通行证、会话及盐，hashlib.scrypt 派生口令哈希，hmac.compare_digest 比较。网页会话与管理口令版本绑定，口令文件被手动移除或换代后旧会话失效。会话只存标识哈希和时间；防伪值由会话凭证派生，不存原凭证。所有操作审计使用固定路由模板与已校验逻辑编号，不记录请求正文、路径原值、认证头或异常原文。

Issue #56 已厘清的技术事项：

1. 在线记忆调用复用子进程已持有的 store 与运行锁，不重复取得运行锁；仍在持锁状态重新校验计划指纹。停止中的管理调用使用同一 MemoryAPI。已知伴侣编号的路径不得扫描其他伴侣的库。
2. 撤销路由只生成计划；执行确认与口令由服务端读取计划 kind/mode 决定。restore 和 undo 执行都要求伴侣停止，new/merge 可在线转交。
3. 插件 CLI 无参数构造后直接取 handler，不调用 start/stop，不提供 ctx；handler 不依赖 start 的状态。按 args Schema 校验，仅传 args 与绑定通行证的 ApiClient。至少一个伴侣配置启用且未卸载才可加载。
4. 卸载由守护进程协调跨伴侣状态，计划绑定状态指纹。实例排除表采用实例级锁内读改写并原子替换，refresh 重读；启用与卸载共享协调锁，避免检查后状态变化。停止伴侣按 U4 列入说明但不改配置，平台/模型必需依赖拒绝卸载。锁复用既有 OS 锁，保留持有者元数据，不删除锁文件。

参考：https://docs.aiohttp.org/en/stable/web_reference.html 、https://yaml.dev/doc/ruamel.yaml/detail/ 。

# chat-timing

按同一发言人的批次合并消息。被 @ 和被引用时直接回应，叫名字时确认是否在叫她。群里主动接话同时考虑最近的发言份额、连续来回、冷落、主人发言和新话题。状态随插件停止清空。

- `judge` 默认 `model`，由本体执行轻量判断；`rules` 使用规则判断。
- `activity` 可选 `low`、`medium`、`high`，默认 `medium`。用 `conversations` 按会话指定积极程度，`schedule` 按实例时间设置时段（支持跨午夜）。
- `tuning` 可调整合并、判断间隔、疲劳与退避参数。秒数、概率及默认值见插件清单。
- 本地 GET 路由 `/plugins/chat-timing/status` 给出各群的积极程度、疲劳、冷落等级、当日判断和自然接话次数。

被叫到时标记本批的回复目标，直接回应时无需发送前复核。连续冷场延长退避时间，积极程度最多降一档。连续来回包含对方在收到回复前连发的情况。状态将未登记群合并显示；插件重载后，已有批次直接继续处理。
